# 模型与额度

## 接入方式

- ChatGPT 订阅：点击登录并在授权页面完成授权。没有 Claude Pro/Max 订阅入口。
- API 密钥：选择厂商并保存密钥。费用与限额由厂商决定。
- 自定义厂商：填写配置 ID、名称、协议、接口地址和模型 ID；可以保存多套。接口获取到的模型 ID 仍需手动确认视觉能力并实测。

OpenAI API 密钥与 ChatGPT 订阅使用不同配置，互不覆盖。厂商表单的“支持图片”只是一项声明。

ChatGPT 模型列表来自当前登录账户的 `GET https://api.openai.com/v1/models`，保留服务端标为可展示的条目和顺序。运行库尚未支持的型号会显示但不能选择；目录获取失败时显示错误，不拿内置 API 清单冒充账户权限。API 密钥模式仍显示厂商运行库目录，实际权限以调用结果为准。依据：[OpenAI 模型与推理说明](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)。

选择模型后可以设置该型号支持的推理强度，点击“设为当前模型”保存。每个厂商/型号分别记住设置，重启保留，执行记录会显示实际强度。非推理模型只有 `off`。使用 Pi SDK 创建的是本应用的智能体会话，不是运行 Codex 或 Claude Code 命令；同型号不代表提示、工具、上下文和产出完全相同。

## 看图测试

网页使用已有 PyMuPDF 生成普通字体随机数字图。模型必须通过实际 read 工具看到图片，并连续三轮完全读对。换模型、修改厂商配置或重新登录后需要重新验证；同一 ChatGPT 账号的登录令牌自动刷新不会使验证失效。测试会使用该模型的额度。

测试通过只能证明这条读图路径可用，不能保证一本书的内容质量。CLI 无法判断模型是否理解了所有证据。
