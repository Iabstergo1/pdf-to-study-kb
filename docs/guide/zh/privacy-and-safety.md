# 隐私与安全

## 本机文件

资料在 books/，知识页在 wiki/，工作记录在 pipeline-workspace/。服务只监听 127.0.0.1，同时校验 Host、Origin 和随机连接令牌。不要把服务转发到公网。

密钥和授权文件放在用户配置目录：Windows 为 %APPDATA%/study-kb，macOS 为 ~/Library/Application Support/study-kb，Linux 为 ~/.config/study-kb。不要把该目录加入版本管理。

## 发送给模型的内容

Git 默认排除 `books/` 中的资料、`wiki/`、`pipeline-workspace/`、依赖目录及构建产物。仓库提供源码、空库模板、离线渲染资源和合成测试数据；不会随克隆提供开发者的书籍或知识库。需要备份时自行备份这些本机目录和用户配置目录；学习记录 JSON 导出只包含个人学习数据，不包含原始资料，也不等于整库备份。

主动启动看图测试、分歧仲裁、AI 入库或知识助手工作流时会调用模型。AI 通过文件工具读取到的文本和图片会发送给选定厂商；厂商的数据处理政策以其服务条款为准。确定性预处理、维护命令与导出本身不调用 LLM。

## 写入与恢复

AI 没有任意 shell，文件工具不能读取凭据目录。入库写作限于 wiki 与当前来源的摘要/裁决文件；旧页修改仍须通过 CLI 的 check-write，最终由 lint 决定是否发布。知识助手按 Skill 限制到查询记录、报告、待审项或已获准的候选页；报告类 Skill 不能直接修改知识页。回存发布、逐项修订和技能采纳会展示具体内容并等待你确认。技能进化只在隔离工作区修改选定 Skill。

这些限制不等于操作系统沙箱。保留原始资料与 Git 历史；不要让多个会话同时编辑这个项目。需要删除来源或重置状态时使用先预览、再确认的维护入口。
