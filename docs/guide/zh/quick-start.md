# 快速开始

Study KB 把资料转成可交叉阅读的概念知识库。所有文件留在本机，AI 写作时会把所读内容发送到你选择的模型厂商。

## 准备环境

需要 Node.js 22.19 或更高版本、Python 3.12。已有 study-kb Conda 环境时直接复用，不要重复安装。

```powershell
conda create -n study-kb python=3.12
conda run -n study-kb python -m pip install -r requirements.txt
```

PDF 严格检查以及扫描件、Word、PowerPoint 解析需要 MinerU。网页的“环境检查”提供安装指引，不会替你执行安装。

## 启动网页

首次在仓库根目录运行：

```powershell
cd web
npm ci
npm run dev
```

浏览器会自动打开本机地址。后续在 `web` 目录运行 `npm start` 即可；更新代码后运行 `npm run build`，再重启服务。使用期间保持终端开启；按 Ctrl+C 停止服务。

如果浏览器没有自动打开，复制终端 `Study KB:` 后面的**完整地址**到浏览器，包括 `#token=…`。只输入 `http://127.0.0.1:8765` 无法建立首次连接。每次重启服务都会生成新地址；看到“请使用启动链接连接”或 `Open the launch link to connect` 时，重新打开当前终端里的完整地址。不要分享其中的连接令牌。

## 开始使用

- 打开“环境检查”，确认 Python 和流水线正常；需要时在“模型与设置”指定解释器完整路径。
- 登录 ChatGPT，或者添加 API 密钥/自定义厂商。选择模型并通过看图测试，再设为当前模型。
- 从“我的资料”上传文件，预处理完成后开始 AI 入库。
- 发布后打开阅读器；“已发布”说明结构检查通过，内容仍待独立验收。

## 知识助手与维护

“知识助手”提供查询、回存、内容审查、逐项审阅、语义检查、复盘、阅读分析、状态诊断和技能进化。查询记录可以继续提问或交给回存；运行时的问题和修改确认显示在执行记录内，切换页面不会丢失。回存先生成候选页，再经你确认执行发布检查。已发布资料卡提供内容审查和按内容报告返工入口。

“维护工具”展示 Python CLI 的全部 59 个命令及其真实参数说明，包括接管旧库、跨库复用、重新封存、迁移原文件和跨域提升。带预览的操作必须先成功预览同一组参数；应用或直接修改状态时须手动输入目标名。接管旧库针对当前工作区的既有 wiki，跨库复用需要原库路径和映射文件，并不会自动生成映射或替你合并内容。

技能进化先检查 Git 工作区干净，再创建隔离分支修改一个 Skill 的双树文件，检查通过后登记候选。查看完整差异并输入候选 ID 后才会重新检查、提交隔离分支并快进合并。网页不替你提交当前已有改动。代码更新后必须重启 Node；新版本会提示运行中的服务代码已过期。
