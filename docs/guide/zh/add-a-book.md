# 添加一本书

## 上传与预处理

选择 PDF、DOCX、PPTX 或 Markdown，填写领域和来源 ID。领域使用小写英文与短横线，例如 research-method；来源 ID 在库中唯一。文件保存在 books/<领域>/input/。

预处理调用现有 Python CLI，完成注册、画像、转换、结构复核、处理窗口和工作单。此阶段不消耗模型额度；PDF 的 MinerU 复核可能需要较长时间和本地模型文件。

## 分歧证据

两种解析方式意见不一致时，使用已通过看图测试的模型阅读证据。模型仍不能确定的页会显示给你：可以保留原图，让后续写作模型阅读；选择忽略时必须说明原因。确认“开始 AI 入库”后，这些步骤自动衔接到写作与发布；只有需要人工裁决时才停下，处理后点“继续入库”。

## AI 入库与恢复

开始前页面会显示资料将发给哪个模型厂商。写作按处理窗口推进；可查看命令动态、用量和日志。一次只处理一本资料，避免与另一个 Codex/Claude 会话同时编辑库。

一次“开始/继续入库”会执行到发布，不需要反复点击。日志中的 `[continue]` 表示阶段汇报后继续当前会话；`[handoff]` 表示本窗记账、U7 摘要实际更新和恢复校验完成后换新会话，继续同一次任务。最后一窗后继续综合整理和发布。普通工具错误会交回模型纠正，连续三轮回答没有完成窗口或阶段进展时会停止；额度、无法读图、流水线状态失败或发布检查失败仍会停止或暂停。网络错误仅按[故障处理](troubleshooting.md)中说明的范围重试。

中止后使用“继续入库”；服务重启后从 CLI 恢复包确定剩余窗口。lint 失败时先看报告，再选择“按报告修复”。被检查器回滚的原页修改需要重新应用，不能只重复点 lint。

## 发布后

结构检查通过后，页面变成 published，并更新阅读数据。“已发布”仅表示发布检查完成；独立内容审查和人工整批验收另外展示。保留原文件，以便核对来源页和公式。


资料详情在所选卡片下展开，固定顶栏的任务入口跨页面保留。收起记录不会停止任务；“中止任务”有单独确认。窗口完成数只统计已阅读并完成记账的窗口，初始化和当前未完成窗口不计入。

“本资料的学习目标”只作用于该资料，保存在该来源的 staging/learning-goal.md；不会追加到全局 wiki/_meta/purpose.md。
