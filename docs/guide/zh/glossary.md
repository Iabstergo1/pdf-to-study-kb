# 术语表

## 资料与知识页

- 来源：一本书、文章或文档，具有唯一 source_id。
- 领域：概念的归属范围；同一本书可以引用其他领域的已有概念。
- 概念页：围绕一个概念组织的知识页，不是章节翻译。
- 综合层：topic、comparison、synthesis 等连接不同概念的页面。

## 流程状态

- 处理窗口：CLI 确定的一段阅读范围，不是 AI 自拟章节或写作单元。
- 工作单：本轮写作允许的路径、快照与进度信息。
- proposed：待检查的内容。
- published：结构检查通过；不表示内容忠实度已独立验收。
- lint：链接、来源、写入记账及渲染安全等确定性检查。

## 查看方式

- vault：wiki 文件夹，网页和 Obsidian 共用。
- 阅读数据：从 published 页面导出的 JSON 与 HTML，可重新生成。
- 分歧仲裁：对两种解析方式的差异选择保留图、忽略或请人判断。


**一次 AI 入库任务**：用户确认后，连续完成该来源剩余的分歧核对、预处理、阅读写作和发布检查。阶段性回答不是任务完成；需要人工决定或错误时停下。

**预处理分歧核对**：AI 判断两种解析器的差异，补齐后续阅读所需证据；属于预处理，不是知识页写作。

**已完成窗口**：原文已阅读且本窗产出已记账的处理窗口。初始化摘要和当前正在处理的窗口不计入。

## 内容审查与验收

- 模型审查记录：模型检查的范围、版本、结论和发现。审查完成后自动登记，不等于用户已认可结果。
- 模型审查完成：选定范围的检查已经结束，仍可能有待处理问题，不保证内容绝对无误。
- 人工已验收：本批相关问题处理完成后，用户对明确范围和版本的整批审查结果作出确认；不要求用户再次逐页重审。
