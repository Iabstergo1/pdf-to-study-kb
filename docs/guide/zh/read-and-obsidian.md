# 阅读与 Obsidian

## 网页阅读

首页提供继续阅读、今日复习和自由自测。目录按总览、跨域综合和领域组织，可以搜索标题、别名、正文并筛选领域、类型和来源。Ctrl+K 聚焦搜索框，方向键选择，回车打开；面包屑打开相应知识列表，返回按钮沿浏览历史恢复阅读位置。

鼠标停留在知识链接上会显示预览，可移入阅读、打开全文或固定到参考栏；移开和 Esc 关闭。宽屏下可以拖动分栏边缘，目录和参考栏可收起；专注模式（Z）突出正文，阅读设置调整字号、行距。窄屏使用可关闭的侧栏。后台任务可从顶栏找回，点击记录外的空白或 Esc 收起，收起不会停止任务。

正文中的 `==高亮==` 在网页显示为高亮，原 Markdown、公式、引用不变。参考栏可以并排查看原书图像和提取文字：关联来自写作窗口时会明确说明，不能把窗口附近页面当作逐句证据。缺少映射时可手动选原文页。图谱内点节点在参考栏预览，切回文章后再返回图谱保留位置。

选中正文可保存个人高亮和批注，也可附原文页提出疑问。批注在个人学习数据中，疑问另写待审记录；两者都不自动修改知识正文。页面改变导致原句无法唯一定位时，会提示重新选句关联。

## 网页学习与备份

“学习与复习”支持计划复习、按来源/领域/页面自由自测、学习设置和历史。题目复用已发布知识页，自测先显示题干，再展开答案与依据链接；没有答案的题目不能评价。

先在学习设置选择加入计划的资料。默认每天最多 20 道不同题，其中新题最多 5 道；到期题优先，未做题目的真实到期日不会被顺延。忘了、吃力、记得、轻松四档评价使用 FSRS 安排下次复习，可撤销最近一次评价。当日已学题到期后的短时巩固会再次出现，不额外占用不同题目的名额。自由自测默认不改变排期，也可以主动计入。暂停后可继续，答案改变会提示重新确认。大幅改写题干产生新题，旧历史保留，不猜测合并。

学习数据保存在本机应用的既有 SQLite 中，换浏览器不丢记录。设置中可导出 JSON 或预览导入；保留本机与替换冲突两种选择会展示受影响数量，替换冲突题也替换其复习历史。学习历史可下载 Markdown。localStorage 只缓存显示偏好和阅读位置，不是复习记录的唯一保存处。

## 报告与待审

“已发布”表示发布检查完成；内容审查另显示本资料的历史覆盖、范围、结论及版本。报告归属以报告或审查记录明确登记的来源为准，旧报告可按文件名中的完整来源 ID 关联；不会因为共享页面后来引用了另一份资料，就把旧报告算作新资料的审查。共享页在其他范围的历史记录单独保留，来源无法确认的旧报告仍可在全部报告和页面历史中查看。旧记录缺少版本证据时显示“历史审查未记录版本”，表示无法自动判断此后是否修改，并非发现内容错误；报告文件缺失也不抹除历史。

在资料详情选择“内容审查”，指定抽样或逐页核对及要求后启动 `kb-qa`。审查先固定知识页范围，模型通过专用读取工具获取页面与当时版本，再对照原文和图片提交结构化结果。CLI 将结果、报告和独立待审项一起登记到既有 SQLite，并生成 `pipeline-workspace/reports/kb-qa/<批次 ID>.md` 与 `.json`。不用手动同步台账；旧 YAML 历史保留，不补造当时版本。仅查看报告或运行 `review-coverage` 不会启动模型审查。

“报告与待审”按批次显示范围、检查方式、逐页结论、待处理问题和人工验收。分母是开始时资料关联的知识页数，不是 PDF 页数；抽样结论只覆盖所列断言。审查未完成、结论不确定、页面已变更或相关问题仍待处理时，不能确认该批验收。修复后点击“复查受影响页面”，重新读取新版本并追加报告；原报告里的发现不被覆盖。问题处置和复查完成后，你阅读整批结果并勾选确认即可，无须逐页重审。共享页以后发生修改，原验收历史保留，受影响页面重新标记待复查。

“逐条待审”包含入库检查、阅读疑问和已登记的模型发现。填写依据后可以关闭、不采纳或暂缓；关闭需要勾选已核查，暂缓保持待处理。原始发现和后续处置分别保存。旧的占位符、概念未被主题收录、写集记账问题可点“复检结构问题”：查看具体证据，勾选要关闭的项目并确认；关闭时会再次检查证据是否改变。结构复检不等于内容审查，发布成功也不会自动清除提案。

需要模型分析时选择“让模型逐条分析”启动 `kb-review`。内容修订另须确认并遵守对应工单保护；`reopen` 重开整个来源的增量流程，不是任意页面的无约束修改接口。审查、问题处置和整批验收本身都不修改原 PDF 或知识正文。

资料和执行记录拆分非缓存输入、缓存读取、输出，支持本次与资料所有已保存执行切换。输入缓存命中率分母是非缓存输入加缓存读取；失败请求可能缺用量。没有适用价格时不编造费用，订阅用量不折算为 API 账单。

## Obsidian

在 Obsidian 中选择“打开文件夹作为仓库”，选中项目的 wiki 文件夹。网页“在 Obsidian 打开”定位同一知识页。原文和知识正文都不因网页渲染或个人批注而改写。在 Obsidian 手动修改后，网页会提示刷新阅读数据。

## 离线站点与 Anki

目录底部仍提供 HTML 和 Anki TSV 导出。先执行导出再下载；带原图的离线站点需要整体拷贝目录。离线 HTML 是阅读快照，Web 的个人学习保存、排期与批注需要本机服务。Anki 可选使用，其排期与网页学习记录互不自动同步。
